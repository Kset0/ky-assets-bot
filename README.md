# KY Assets Bot

Discord bot that watches Supabase for new purchases and DMs the buyer their RBXL file.

## Environment Variables (set these in Koyeb)

| Variable | Value |
|---|---|
| DISCORD_TOKEN | Your bot token |
| SUPABASE_URL | https://ondfbtumgpgofeqimckp.supabase.co |
| SUPABASE_ANON_KEY | Your Supabase anon key |
| GUILD_ID | 1507853042135994528 |
| OWNER_ID | 1350282344988409940 |

## Deploy to Koyeb
1. Push this folder to a GitHub repo
2. Connect repo to Koyeb
3. Set the environment variables above
4. Deploy
